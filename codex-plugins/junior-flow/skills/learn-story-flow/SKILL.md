# Learn Story Flow

Accept an optional topic: `technical-design`, `review-implementation`, or `bdd-scenarios`.

If a topic is supplied, load `junior-flow:learn-<topic>`.

If no topic is supplied, present these choices:

| Topic | Description |
| --- | --- |
| `technical-design` | Why discuss technical design before implementation? |
| `review-implementation` | Why review implementation even with 100% test coverage? |
| `bdd-scenarios` | What defines effective, complete BDD scenarios? |

After the developer selects a topic, load the corresponding skill. If the requested topic does not exist, explain that and show the same choices.
